DeepSeek Harness Portable 1.0.2
==============================

把官方 DeepSeek Harness 放进一个可移动文件夹。
Official Harness 0.2.1-rc.2 / Node.js 24.21.0 / pnpm 11.28.0

Windows x64: double-click windows.bat
Linux x64 (glibc): sh linux.sh
macOS Apple Silicon: sh mac.sh

首次安装需要联网。打开终端中 dsh web: 打印的完整地址，按 Ctrl+C 停止后再复制文件夹或拔出设备。
数据与凭据位于 data/，不要公开分享已含个人数据的文件夹。
Data and credentials stay in data/. Do not publish personal installations.
